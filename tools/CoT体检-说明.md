# CoT 体检 · 怎么跑

## 一句话：现在在测什么
问中转站一句话，把它**原话**（未经我们解析的 SSE 帧）抄回来，看**「思考过程 / CoT」到底藏在哪个字段**。

结果是三选一，每条路接下来动的地方不一样：

| 结果 | 意思 | 接下来动哪 |
|---|---|---|
| **A** | 中转站**给了**单独字段，被我们网关解析时丢掉了 | 动房子里的**网关**（改动小、能离线验收） |
| **B** | 思考链**内联在正文里**（`<thinking>…</thinking>`） | 动**网页显示逻辑**（把它抽出来单独显示） |
| **C** | 中转站**压根没给** | 一行代码不用改，先在 Zeabur 配个参数再重跑 |

## 怎么跑（两种都行，都不用打命令）

**方式一（推荐）：双击 `tools\CoT体检.bat`**

**方式二：** 在 kael-home 里右键 `tools\cot_doctor_file.py` → 用 Python 打开

两种都是同一个流程：

1. **自动弹一个记事本** → 把 `RELAY_SECRET` 粘到 `PASTE_HERE` 那一行 → **Ctrl+S** 保存 → 关掉记事本
2. 剩下全自动：验钥匙 → 自动挑模型 → 抄上游原话 → 打印结论
3. 结果同时存到 `tools\cot_probe_result.json`

## 你不需要记的东西（脚本已经替你做了）

- **不用抄模型名** —— 自动从房子的允许列表里取
- **不用管格式** —— 首尾空白 / 换行 / 零宽字符 / BOM 自动清掉
- **不用怕出错** —— 401 / 400 / 5xx 会分别告诉你是什么原因，而不是笼统说"密码不对"
- **密钥不外泄** —— 只打印长度、首末字符、sha256 前 12 位，**从不打印密钥本身**

## ⚠️ 两个容易踩的点

1. **密钥中间如果有一个空格，那是内容的一部分，要一起粘。**
   （曾经因为把空格当脏字符清掉，白白卡了一轮）
2. **改过 Zeabur 环境变量后，必须重新部署才生效。**
   环境变量是容器启动时注入的，不重启还是用旧值 —— 401 十次里有九次是这个。
